BuildTurn ROMs into PSP apps

Drop a ROM.
Get a PSP icon.

Each game becomes its own app on the PSP Memory Stick menu, with its own icon, background picture and menu sound, and starts straight into the game. No RetroArch menus.

    RepairFix zips you already built

    Saves not sticking, so the game starts fresh every time? Older zips lack the settings file and save folders the PSP cores need (PSP/RETROARCH). Drop one or many old PSP_Games.zip files here and get fixed copies back. Your games, art and sound are copied as they are; nothing is rebuilt or uploaded.

    InstallPut the games on the Memory Stick
    1. Connect the PSP to your computer. On the PSP choose Settings, USB Connection, or take the Memory Stick out and use a card reader.
    2. Unzip the download. Copy the whole PSP folder from the zip onto the PSP folder of the Memory Stick (it holds GAME with your games and RETROARCH with the save settings, and both are needed). If it asks, merge.
    3. Unplug, then open Game, Memory Stick on the XMB. Each game has its own icon and background, and its sound plays while it is highlighted.
    4. Start with one game to check it works before copying lots. If something is missing, the PSP shows which file it could not find.
    5. Big games (GBA, SNES, Mega Drive and anything over a few MB): in ARK's settings, set Use extra memory to Max. Without it the PSP can show a black screen and switch itself off when the game starts. Zelda: The Minish Cap (16 MB) needs this.
    6. Press HOME to quit back to the XMB. Game saves (.srm) and an automatic resume point (.state.auto) are written inside each game's own folder next to its ROM, so every game keeps its own progress. Do not delete them, and do not delete PSP/RETROARCH/retroarch.cfg; without it nothing is saved. If you copy the build over an older copy of a game, choose merge and keep the existing saves.

    Memory tip: if a game goes black and the PSP powers off, set ARK's Use extra memory to Max and try again. PSP-2000 and 3000 only.

    Needs a PSP running custom firmware such as ARK. Only systems that run well on a PSP-3000 are accepted: N64, PS2, GameCube, Dreamcast and Saturn are too heavy, and PS1 games are better run with the PSP's built-in PS1 support.
