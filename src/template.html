Drop a ROM.
Get a PSP icon.

Each game becomes its own app on the PSP Memory Stick menu, with its own icon and background, and starts straight into the game. No RetroArch menus.

    Put them on the PSP

    1. Connect the PSP to your computer. On the PSP choose Settings, USB Connection, or take the Memory Stick out and use a card reader.
    2. Unzip the download. Copy the GAME folder contents (the game folders) into PSP/GAME on the Memory Stick. If it asks, merge.
    3. Unplug, then open Game, Memory Stick on the XMB. Each game has its own icon.
    4. Start with one game to check it works before copying lots. If something is missing, the PSP shows which file it could not find.
    5. Press HOME to quit back to the XMB. Saves are written to PSP/RETROARCH on the stick, and every game gets its own file.

    Needs a PSP running custom firmware such as ARK. Only systems that run well on a PSP-3000 are accepted: N64, PS2, GameCube, Dreamcast and Saturn are too heavy, and PS1 games are better run with the PSP's built-in PS1 support.
